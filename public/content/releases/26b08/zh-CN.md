# Lingmo OS 5.0 26b08（Lithium）

**发布日期：** 2026 年 11 月 28 日

### 新增功能

- 设置中的更新页面在检测到更新时，在“立即更新”下增加“重新检查”操作。
- 设置中加入 Stage Manager 开关，配置保存为 `StageManager/Enabled`，由合成器偏好监听器即时应用。
- 设置中新增“控件样式”选择
- 新增“高效模式”界面

### 更新

- 内核更新至7.3.4
- 更新“照片”应用
- 更新“时钟”应用
- Aurora 更新至 `1.2.3`，并同步 Debian 软件包版本。
- 关于页面改为读取已安装的 `aurora-version` 元数据。
- 未保存用户偏好时 Stage Manager 默认关闭，已明确保存的偏好保持不变。
- Debian 更新至13.8

### 优化

- 优化 Stage Manager 卡片：使用完整卡片缩略图、叠加应用图标、交替倾斜效果，并按最近使用顺序排列。

### 问题修复

- 系统通知以非交互覆盖层出现时不再关闭启动台。
- 文件夹重命名后点击启动台空白区域只提交重命名，不再关闭启动台。
- 文件管理器属性窗口根据内容调整大小，并将页面内容居中。
- 修复打开属性窗口导致桌面崩溃的问题
- 修复视频播放器无法正常播放视频的问题

### 发布范围

本发行注记覆盖 26b08 批次中已发布的软件包变更。
