# Lingmo OS 5.0 26b08（Lithium）

**發布日期：** 2026 年 11 月 28 日

### 新增功能

- 設定中的更新頁面在偵測到更新時，於「立即更新」下方新增「重新檢查」操作。
- 設定中新增 Stage Manager 開關，設定儲存為 `StageManager/Enabled`，並由合成器偏好設定監聽器即時套用。
- 設定中新增「控制項樣式」選項。
- 新增「高效模式」介面。

### 更新

- 核心更新至 7.3.4。
- 更新「照片」應用程式。
- 更新「時鐘」應用程式。
- Aurora 更新至 `1.2.3`，並同步更新 Debian 套件版本。
- 「關於」頁面改為讀取已安裝的 `aurora-version` 中繼資料。
- 未儲存使用者偏好設定時，Stage Manager 預設為關閉；已明確儲存的偏好設定則保持不變。
- Debian 更新至 13.8。

### 優化

- 優化 Stage Manager 卡片：採用完整卡片縮圖、疊加應用程式圖示、交替傾斜效果，並依最近使用順序排列。

### 問題修復

- 系統通知以非互動式覆蓋層顯示時，不再關閉啟動台。
- 資料夾重新命名後，點擊啟動台空白區域只會提交重新命名，不再關閉啟動台。
- 檔案管理員的屬性視窗會根據內容自動調整大小，並將頁面內容置中。
- 修復開啟屬性視窗時導致桌面崩潰的問題。
- 修復影片播放器無法正常播放影片的問題。

### 發布範圍

本發行說明涵蓋 26b08 批次中已發布的軟體套件變更。
