# Lingmo OS 5.0 26b08（Lithium）

**發布日期：** 2026 年 11 月 25 日

### 新功能

- 設定的更新頁面在有可用更新時，於「立即更新」下方加入「重新檢查」操作。
- 設定中加入 Stage Manager 開關，儲存為 `StageManager/Enabled`，由合成器偏好監聽器即時套用。

### 更新

- Aurora 更新至 `1.1.12`，並同步 Debian 套件版本。
- 關於頁面改為讀取已安裝的 `aurora-version` 中繼資料。
- 沒有已儲存的使用者偏好時，Stage Manager 預設關閉；已明確儲存的偏好維持不變。

### 優化

- 改善 Stage Manager 卡片：使用完整卡片縮圖、疊加應用程式圖示、交錯傾斜效果，並依最近使用順序排列。

### 問題修復

- 系統通知以非互動覆蓋層顯示時，不再關閉啟動台。
- 資料夾重新命名後點擊啟動台空白處，只會提交重新命名，不會關閉啟動台。
- 檔案管理員屬性視窗會依內容調整大小，並將頁面內容置中。

### 發布範圍

本發行注記涵蓋 26b08 批次中已發布的軟體套件變更。待發布的 Stage Manager 初始實作與架構研究不列入本次功能清單。
