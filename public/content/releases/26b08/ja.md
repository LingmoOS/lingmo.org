# Lingmo OS 5.0 26b08（Lithium）

**リリース日:** 2026年11月25日

### 新機能

- 設定の更新ページで更新が利用可能な場合、「今すぐ更新」の下に「再チェック」を追加しました。
- 設定に Stage Manager スイッチを追加しました。設定は `StageManager/Enabled` に保存され、コンポジターの設定監視によって即時反映されます。

### 更新

- Aurora を `1.1.12` に更新し、Debian パッケージのバージョンも同期しました。
- About ページがインストール済みの `aurora-version` メタデータから Aurora のバージョンを読み取るようになりました。
- ユーザー設定が保存されていない場合、Stage Manager は既定で無効になります。明示的に保存された設定は維持されます。

### 最適化

- Stage Manager のカードを改善し、カード全体のサムネイル、アプリケーションアイコンの重ね表示、交互の傾き、最近の使用順に対応しました。

### 修正

- 非対話型オーバーレイとして通知バナーが表示されても、ランチャーを閉じなくなりました。
- フォルダー名の変更後にランチャーの空白部分をクリックすると、名前変更だけを確定し、ランチャーは閉じません。
- ファイルマネージャーのプロパティウィンドウが内容に合わせてサイズ変更され、ページ内容が中央揃えになります。

### 対象範囲

このリリースノートは 26b08 バッチで公開されたパッケージ変更を対象とします。保留中の Stage Manager 初期実装とアーキテクチャ調査は公開機能一覧に含めていません。
