# Lingmo OS 5.0 26b08（Lithium）

**リリース日：** 2026年11月28日

### 新機能

- 設定のアップデートページで更新が検出された際、「今すぐ更新」の下に「再確認」操作を追加しました。
- 設定に Stage Manager のオン／オフ切り替えを追加しました。設定は `StageManager/Enabled` に保存され、コンポジターの設定監視機能によって即座に適用されます。
- 設定に「コントロールスタイル」の選択項目を追加しました。
- 「効率モード」のインターフェースを追加しました。

### アップデート

- カーネルを 7.3.4 に更新しました。
- 「写真」アプリを更新しました。
- 「時計」アプリを更新しました。
- Aurora を `1.2.3` に更新し、Debian パッケージのバージョンも同期しました。
- 「このシステムについて」ページで、インストール済みの `aurora-version` メタデータを読み取るように変更しました。
- ユーザー設定が保存されていない場合、Stage Manager はデフォルトで無効になります。明示的に保存された設定はそのまま維持されます。
- Debian を 13.8 に更新しました。

### 改善

- Stage Manager のカード表示を改善しました。カード全体のサムネイル、アプリアイコンのオーバーレイ、交互に傾ける視覚効果を採用し、最近使用した順に並べるようにしました。

### バグ修正

- システム通知が非インタラクティブなオーバーレイとして表示される際、ランチャーが閉じなくなるよう修正しました。
- フォルダーの名前変更後にランチャーの空白領域をクリックしても、名前の変更のみが確定され、ランチャーが閉じないよう修正しました。
- ファイルマネージャーのプロパティウィンドウがコンテンツに応じてサイズを自動調整し、ページ内容が中央に配置されるようにしました。
- プロパティウィンドウを開くとデスクトップがクラッシュする問題を修正しました。
- 動画プレーヤーで動画を正常に再生できない問題を修正しました。

本リリースノートは、26b08 ビルドで公開されたソフトウェアパッケージの変更を対象としています。
